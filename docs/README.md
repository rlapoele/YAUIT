# Project memory

The repository records knowledge according to its maturity:

- [`current.md`](current.md): current phase, active focus, and next step.
- [`vision.md`](vision.md): accepted problem, audience, outcome, and boundaries.
- [`ideas/`](ideas/README.md): candidate directions and assumptions under exploration.
- [`research/`](research/README.md): evidence, comparisons, and experiments.
- [`decisions/`](decisions/README.md): explicitly accepted product and architecture decisions.
- [`specs/`](specs/README.md): behavior and contracts precise enough to implement.
- [`plans/`](plans/README.md): ordered implementation work derived from accepted specifications.
- [`sessions/`](sessions/README.md): concise historical discussion records.

Later-stage records take precedence over earlier-stage material. A decision overrides an idea; an accepted specification governs implementation; current source code does not silently redefine an accepted contract.
