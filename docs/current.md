# Current state

- **Phase:** Ideation
- **Active focus:** Define the presentation-unit model and its contract with JavaScript behaviors.
- **Accepted product direction:** A small, buildless-first HTML activation and composition library centered on presentation units, reusable behaviors, and explicit contracts.
- **Accepted architecture or technology stack:** Standard HTML and JavaScript are first-class. A small activation kernel with optional capabilities is the current architectural direction; no public API or implementation design is accepted.
- **Implementation:** None.

## Next step

Define what qualifies as a YAUIT presentation unit or component, including the relationship among existing DOM subtrees, `<template>` elements, custom elements, and composed units.
